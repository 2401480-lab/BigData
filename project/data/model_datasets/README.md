# 기능 카테고리 분류용 원본 데이터셋 등급

이 폴더는 행 단위 학습 후보가 아니라 **원본 데이터셋 단위**로 분류한 구조다. 원본 파일 전체를 복제해 둔 것이며, Gold 파일끼리 스키마 정렬·정제·전처리·통합을 먼저 수행한다.

## 폴더 의미

| 폴더 | 의미 | 현재 사용 단계 |
| --- | --- | --- |
| `gold/` | 기능 카테고리 라벨과 모델 입력 피처가 함께 있어 1차 학습 데이터셋 구축에 적합한 원본 | 먼저 스키마 통합 후 학습·검증·테스트 데이터셋 생성 |
| `silver/` | 기능 라벨은 있으나 규모·범위·품질 제약이 있어 Gold 모델 구축 뒤 보조 학습 또는 외부 검증에 쓰는 원본 | Gold 기준 모델 이후 사용 |
| `unlabeled/` | 기능 카테고리 정답이 없거나, 중복 옵션·범위 불확실성 때문에 독립 학습셋으로 적합하지 않은 원본 | 모델 예측, 피처 보강, 범위 판정, 옵션 정보 보완에 사용 |

## Gold 데이터셋

### `danawa_dogfood.csv` — Gold

- 2,470개 상품 중 1,830개에 상품상세정보에서 파싱한 기능 정보가 있다.
- 조단백·조지방 등 영양성분, 원료·기능·처방식·사료형태, 가격·평점·리뷰를 함께 가진 한국어 데이터다.
- 소화·관절·피부·체중 등 한국어 기능 카테고리의 주요 학습 근거가 된다.
- 단, 기능은 상세정보에서 파싱된 값이므로 원문 보존과 표본 검수가 필요하다.

### `zooplus_dog_food.csv` — Gold

- 3,551개 상품 중 1,690개에 사이트 `기능` 라벨이 있다.
- 원료 3,533건, 상세설명 3,551건, 사료형태·생애주기·견종크기·영양성분·가격 정보를 가진 가장 큰 기능 라벨 출처 중 하나다.
- `Stomach & digestive care`, `Joints & bone care`, `Renal care`처럼 기능 정의가 비교적 명확하다.
- 영어 중심이므로 다국어 텍스트 정규화와 출처 홀드아웃 검증이 필요하다.

### `petsathome_dog_food.csv` — Gold

- 1,595개 상품 중 670개에 `기능` 라벨이 있다.
- 원료 1,594건과 영양·처방식·사료형태·가격·리뷰 정보를 함께 보유한다.
- 한국어로 정리된 소화기·피부·체중·관절·비뇨기·신장 등의 기능 라벨을 제공해 국내 라벨 체계 연결에 유용하다.
- 기능이 비어 있는 행은 기능이 없다는 뜻이 아니므로 음성 라벨로 처리하지 않는다.

### `petsmart_dryfood_product.csv` — Gold

- 상품 단위 838건이며, 이 중 479건은 `hc_source=curated`로 표시된 선별 기능 라벨을 가진다.
- 원료 803건, 보증성분 775건, 조단백 767건, 조지방 760건, 조섬유 763건, 수분 764건 등 입력 피처 품질이 좋다.
- 글루코사민·콘드로이틴·오메가·프로바이오틱스 등 관절·소화·피부 관련 보조 성분을 제공한다.
- `hc_source=text` 라벨은 이 파일 안에 함께 있지만 Gold 정답으로 바로 쓰지 않고 Silver 성격의 보조 라벨로 분리한다.
- 카테고리는 개 건사료지만 `species=Cat`인 2건이 있어 `species_conflict` 플래그로 검수한다.

## Silver 데이터셋

### `purina_uk_dog_food.csv` — Silver

- 119개 상품 중 42개만 기능 라벨이 있다.
- 영양성분·원료·사료형태가 비교적 잘 정리돼 있어 보조 학습과 외부 검증에는 유용하다.
- 전체 규모가 작고, 31개가 간식(`is_treat=True`)이어서 Gold 학습셋의 중심 데이터로 쓰기에는 편향 위험이 있다.
- Gold 모델을 구축한 뒤, 성능 변화와 영국 브랜드 일반화 여부를 확인하는 보조 데이터로 사용한다.

## Unlabeled 데이터셋

### `dog_food_nutrition_disclosed_lifeofepic_dry_2026-10-28.csv`

- 건식 사료 799건의 조단백·조지방·주원료 정보가 있지만 기능 카테고리 정답이 없다.
- 학습 정답에는 쓰지 않고, Gold 모델이 완성된 뒤 소화·피부·관절 등 기능을 예측할 대상으로 사용한다.

### `dogpre_dog_food_nutrition_2026-10-28_idx1150-1269.csv`

- 37개 건식 주식사료에 단백질·지방·섬유·회분·칼슘·인·수분과 원료 정보가 있다.
- 기능 카테고리가 없고 규모가 작아 독립 학습 데이터셋으로는 부적합하다.
- 예측 결과의 한국어 사례 검토와 영양 피처 보완에 사용한다.

### `en.openpetfoodfacts.org.products.csv`

- 15,136개 레코드의 대규모 외부 데이터지만 반려견 외 동물 식품이 섞여 있고 건강 기능 라벨이 없다.
- 기능 학습 정답으로 사용하지 않는다.
- 반려견 범위 판정 후 원료·영양 보강 또는 모델 추론 대상으로 활용한다.

### `petsmart_dryfood_sku.csv`

- 1,615개 SKU지만 838개 상품(`master_id`)의 용량·가격·GTIN 변형이다.
- 상품 단위 Gold 데이터와 중복되므로 독립 학습 행으로 사용하면 데이터 누수가 발생한다.
- 가격·용량·GTIN 정보를 Gold 상품에 보완하는 확장 데이터로만 사용한다.

## 별도 보관 대상

- `dog_food_merged.csv`는 여러 출처를 32개 공통 컬럼으로 축소한 과거 통합본이다.
- 원문 라벨·옵션·상세 영양·출처 메타데이터의 일부가 축소돼 있으므로, Gold 원본 통합의 기준 데이터로 사용하지 않는다.
- `기능카테고리사전.csv`는 Gold 원본의 기능 라벨을 표준 카테고리로 정규화하고 학습 채택 여부를 정하는 규칙 파일이다. 원본 데이터셋은 아니다. 기존 `카테고리딕셔너리.csv`를 대체한다 (선정 기준: `project/md/function_category_criteria.md`).

## 이후 작업 순서

1. Gold 파일 4개만 대상으로 공통 스키마를 정의한다.
2. 원문 라벨을 `기능카테고리사전.csv`로 표준화한다. (완료: 통합 데이터의 `기능카테고리`·`학습카테고리` 컬럼)
3. Gold 공통 피처를 정제한다. 결측·단위·최소/최대 보증치·이상치를 출처별 규칙으로 처리한다.
4. 상품·옵션 중복을 `group_id`로 묶고 Gold 내부에서 학습·검증·테스트를 나눈다.
5. Gold 기준 모델을 학습한다.
6. Silver의 Purina로 보조 학습 또는 외부 검증을 수행한다.
7. Unlabeled 데이터에 예측을 적용하고, 높은 신뢰도의 결과만 보완 라벨 후보로 사용한다.
