## 김서영
## 속성 설명

| 속성명 | 설명 |
|---|---|
| `site` | 수집 사이트 구분 (`uk` 또는 `ie`) |
| `product_id` | 해당 국가 사이트 URL에서 추출한 상품 식별자 |
| `brand` | 상품 브랜드 |
| `name` | 상품명 |
| `category` | 사이트 상품 분류를 정규화한 유형 (`건식` 또는 `습식`) |
| `생애주기` | 대상 반려견 생애주기 (복수값은 `|`로 구분) |
| `견종크기` | 대상 견종 크기 분류 (복수값은 `|`로 구분) |
| `기능` | 상품의 건강·기능 관련 분류 (예: 체중 관리, 신장 관리, 피부 관리) |
| `특수식단` | 사이트의 특수 식단 분류. 이 CSV에서는 모든 행이 공란 |
| `맛` | 표시된 맛 또는 주요 원료 풍미 (복수값은 `|`로 구분) |
| `조단백` | 조단백질 함량 (%) |
| `조지방` | 조지방 함량 (%) |
| `조섬유` | 조섬유 함량 (%) |
| `조회분` | 조회분 함량 (%) |
| `수분` | 수분 함량 (%) |
| `칼슘` | 칼슘 함량 (%) |
| `인` | 인 함량 (%) |
| `나트륨` | 나트륨 함량 (%) |
| `kcal_per_kg` | 킬로그램당 열량 (kcal/kg) |
| `url` | 상품 상세 페이지 URL |
| `breadcrumb` | 사이트 탐색 경로·카테고리 경로 |
| `rating` | 사이트 상품 평점 |
| `review_count` | 사이트 상품 리뷰 수 |
| `description` | 상품 상세 설명 |
| `n_variants` | 상품에 연결된 용량·옵션 변형 개수 |
| `gtin` | 변형 상품의 GTIN/바코드 (복수값은 `|`로 구분) |
| `sizes` | 변형 상품의 용량·옵션 이름 (복수값은 `|`로 구분) |
| `currency` | 가격 통화 코드 (`GBP` 또는 `EUR`) |
| `price_min` | 상품 변형 중 최저 가격 (해당 `currency` 기준) |
| `price_max` | 상품 변형 중 최고 가격 (해당 `currency` 기준) |
| `price_per_kg_min` | kg 단위 가격 정보가 있는 경우의 최저 단위 가격 (해당 통화/kg) |
| `사료형태` | 사이트 상품 속성에 표시된 사료 형태 (예: Dry food, Wet food) |
| `포장` | 사이트 상품 속성에 표시된 포장 형태 |
| `견종` | 사이트 상품 속성의 특정 견종 정보 |
| `ingredients_full` | 원재료·첨가물 페이지 영역에서 추출한 전체 원문 |
| `ingredients` | 전체 원문에서 분리한 원재료 설명 |
| `additives` | 전체 원문에서 분리한 첨가물 설명 |
| `constituents_variant` | 분석 성분표에서 선택된 첫 번째 변형·맛 옵션 |
| `n_constituent_options` | 분석 성분표에서 선택할 수 있는 변형·맛 옵션 개수 |
| `constituents_raw` | 분석 성분표 원문을 항목과 값의 JSON 객체로 저장한 문자열 |
| `타우린` | 타우린 함량 (%) |
| `오메가3` | 오메가-3 함량 (%) |
| `오메가6` | 오메가-6 함량 (%) |
| `마그네슘` | 마그네슘 함량 (%) |
| `칼륨` | 칼륨 함량 (%) |
| `탄수화물` | 탄수화물 함량 (%) |
| `전분` | 전분 함량 (%) |
| `카르니틴` | 카르니틴 함량 (%) |
| `염소` | 염소 함량 (%) |
| `글루코사민` | 글루코사민 함량 (%) |
| `dm_조단백` | 건물 기준 조단백 함량 (%) |
| `dm_조지방` | 건물 기준 조지방 함량 (%) |
| `dm_조섬유` | 건물 기준 조섬유 함량 (%) |
| `dm_조회분` | 건물 기준 조회분 함량 (%) |
| `dm_칼슘` | 건물 기준 칼슘 함량 (%) |
| `dm_인` | 건물 기준 인 함량 (%) |
| `dm_나트륨` | 건물 기준 나트륨 함량 (%) |
| `is_dup` | 앞서 나온 행과 GTIN이 겹치는 상품이면 `True`, 아니면 `False` |
| `영양정보_있음` | 조단백 값이 있어 영양정보가 있는 것으로 판정되는지 여부 |

## 손경빈

### 명견에픽
| 컬럼명 | 의미 |
| --- | --- |
| `source_site` | 데이터를 수집한 사이트명 |
| `source_type` | 사이트 유형: 사료 비교·판매가격 정보 사이트 등 |
| `brand` | 사료 브랜드명 |
| `product_name` | 사료 제품명 |
| `food_method` | 사료 형태: 건식, 키블 등 |
| `crude_protein_percent` | 조단백질 수치(%) |
| `crude_protein_label` | 조단백질 원문 표기값. 예: `25% 이상` |
| `crude_fat_percent` | 조지방 수치(%) |
| `crude_fat_label` | 조지방 원문 표기값. 예: `14% 이상` |
| `main_ingredients` | 제품 페이지에 표기된 주요 원료 |
| `source_url` | 해당 제품의 원본 상세 페이지 주소 |
| `list_page` | 제품 URL을 수집한 목록 페이지 주소 |
