# 기능 카테고리 선정 기준

작성일: 2026-11-03  
대상: `data/model_datasets/unified/gold_unified.csv`의 `기능_원문`  
매핑 사전: `data/model_datasets/기능카테고리사전.csv` (기존 `카테고리딕셔너리.csv` 대체)  
시각화: `EDA/gold_unified_eda.ipynb` 3절

## 1. 목적

Gold 데이터의 기능 라벨 원문은 4개 출처에서 79종이며, 출처끼리 겹치는 라벨이 하나도 없다. 같은 기능도 출처마다 이름이 다르고(예: `소화·장건강` / `Stomach & digestive care` / `소화기` / `Digestive Care`), 1~3건뿐인 라벨도 많다. 이 문서는 원문 라벨을 표준 카테고리로 묶고, 그중 **모델 학습에 쓸 카테고리를 정량 기준으로 선정한** 과정을 기록한다.

선정 결과는 **10개 카테고리**다: digestive, skin_coat, joint_bone, weight_management, immune, dental_oral, vision, heart, renal, urinary.

## 2. 선정 절차

### 2.1 1단계: 정의 기준 (건수를 세기 전에 적용)

1. **동의어 통합**: 원문 라벨을 `기능카테고리사전.csv`로 표준 카테고리에 매핑한다. 한 원문 라벨이 여러 카테고리에 대응할 수 있다(다나와 `신장·요로건강` → renal, urinary).
2. **건강기능만 대상**: 사전의 `유형`이 `health_function`인 카테고리만 센다. 다음은 건수와 관계없이 정의상 제외한다.

   | 유형 | 예 | 제외 이유 |
   | --- | --- | --- |
   | `diet_trait` (식이특성) | Sensitive, Hypoallergenic, 저알러지 | 기능이 아니라 식이 특성 |
   | `target_trait` (대상특성) | Performance, Sterilised, Senility | 대상 동물의 특성 |
   | `umbrella_tag` (포괄태그) | General Health | 특정 기능을 가리키지 않음 |
   | `support_function` (보조기능) | Muscle Tone, Appetite support | 건강기능과 별도 검토 대상 |

3. **집계 단위**: 상품 1개에 같은 카테고리가 여러 원문으로 붙어도 1건으로 센다. 중복 상품(`중복여부=True`, 1,032행)은 제외한다. 집계 대상은 중복을 뺀 Gold 상품 3,637개이며, 건강기능 카테고리 부착 건수는 총 5,553건이다.

### 2.2 2단계: 정량 기준 (모비율 신뢰구간)

카테고리별 성능(재현율)을 평가할 수 있을 만큼 양성 표본이 있는 카테고리만 채택한다. 재현율은 비율이므로, 비율 추정의 95% 신뢰구간 오차 E와 필요한 표본 수 n은 다음과 같다.

$$E = z\sqrt{\frac{p(1-p)}{n}} \quad\Longrightarrow\quad n = \frac{z^2\,p(1-p)}{E^2}$$

| 모수 | 값 | 근거 |
| --- | --- | --- |
| 신뢰수준 | 95% (z = 1.96) | 통계 분석의 표준 관례 |
| p | 0.5 | 재현율을 미리 알 수 없으므로 n이 가장 커지는 보수적 값 |
| 허용 오차 E | ±10%p | 표본조사에서 탐색적 연구에 관례적으로 쓰는 값 (정밀 조사 ±3~5%p) |
| 평가 방식 | 5-fold 교차검증 | 모든 상품이 한 번씩 평가에 쓰이므로 평가 표본 = 전체 N |

$$n = \frac{1.96^2 \times 0.5 \times 0.5}{0.10^2} = 96.04 \;\rightarrow\; \textbf{97건 (올림)}$$

**채택 규칙: 중복 제외 상품 수 N ≥ 97인 건강기능 카테고리를 채택한다.**

## 4. 민감도 분석

기준값을 바꿨을 때 채택 개수가 어떻게 달라지는지 확인했다. 상위 순위는 항상 같고 기준선의 위치만 움직인다.

| 허용 오차 E | 필요 양성 n | 5-fold 교차검증 (N ≥ n) | 8:2 분할 (N ≥ n/0.2) | 8:1:1 분할 (N ≥ n/0.1) |
| ---: | ---: | ---: | ---: | ---: |
| ±5%p | 385 | 5개 | 0개 | 0개 |
| **±10%p** | **97** | **10개 (채택안)** | 4개 | 2개 |
| ±15%p | 43 | 11개 | 6개 | 4개 |
| ±20%p | 25 | 12개 | 9개 | 5개 |

평가 방식을 단일 분할로 바꾸면 평가 표본이 20%(8:2) 또는 10%(8:1:1)로 줄어 같은 오차에 필요한 전체 건수가 5배·10배가 된다. 이 때문에 5-fold 교차검증을 평가 방식으로 정했다.

## 5. 한계

1. **다나와 편중**: 모든 채택 카테고리에서 다나와 비중이 가장 크다(59~97%). 특히 vision은 97%가 다나와다. 모델이 기능이 아니라 출처의 특징을 학습할 위험이 있으므로, 평가 시 출처별 성능을 따로 확인한다.
2. **renal과 urinary의 구분**: 다나와 원문 `신장·요로건강`이 두 카테고리에 함께 매핑되어, 다나와의 renal 82건과 urinary 82건은 같은 상품이다. 다나와 데이터만으로는 두 기능을 구분할 수 없다.
3. **교차검증 오차는 근사값**: 5개 모델의 학습 데이터가 서로 겹쳐 회차별 결과가 독립이 아니므로, 위 공식의 오차는 실제보다 약간 낙관적이다. 성능 보고 시 회차별 평균과 표준편차를 함께 제시한다.
4. **학습카테고리가 없는 Gold 상품**: Gold 4,669개 중 1,316개는 채택 카테고리가 하나도 없다. 대부분 `Sensitive`, `저알러지`, `General Health`처럼 건강기능이 아닌 라벨만 가진 상품이다. 이들을 "모든 기능 없음(음성)"으로 학습에 쓸지는 모델링 단계에서 정한다. 단, `General Health`는 개별 기능의 음성 라벨로 쓰지 않는다(사전 비고).

## 6. 산출물과 사용법

| 파일 | 내용 |
| --- | --- |
| `data/model_datasets/기능카테고리사전.csv` | 원문 라벨 98행의 매핑. 열: `출처`, `원문라벨`, `카테고리`, `카테고리명`, `유형`, `학습채택`(adopted/held/excluded), `비고` |
| `gold_unified.csv`, `unified_all.csv`의 `기능카테고리` | 상품의 건강기능 카테고리 전체 (채택·보류) |
| 같은 파일의 `학습카테고리` | 그중 채택 10개만. 모델의 정답 라벨 |

- 사전은 출처별로 1행씩 적는다. Purina UK 행은 현재 통합 데이터에 없지만 이후 통합을 위해 남겼다.
- 기준을 바꾸면(예: 허용 오차 변경) 사전의 `학습채택` 열을 고친 뒤 `scripts/gold_unified/build_dataset.py`를 다시 실행한다. EDA 노트북 3절은 같은 공식으로 판정을 다시 계산해 사전과 일치하는지 확인한다.
- 사전에 없는 원문 라벨이 들어오면 해당 행의 `품질플래그`에 `기능라벨_사전없음`이 붙는다.
