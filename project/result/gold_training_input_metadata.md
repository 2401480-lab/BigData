### 3.1 건물기준 성분

건물기준 값은 수분을 뺀 고형분 기준이다. 건식과 습식을 같은 눈금에서 비교할 수 있다.

- 계산식: 현물값 ÷ (1 − 수분/100)
- **건식의 추정 수분:** 수분이 없는 건식은 하위 형태별 실측 수분 중앙값으로 계산했다. 일반 건식 10.0%, 동결건조 6.0%, 에어드라이 14.0%, 탈수건조 8.25%다.
  - 추정 오차는 조단백 기준 중앙값 0.31%p다.
  - 이 파일에는 추정 여부(`수분추정여부`)가 없다. 필요하면 원본에서 `출처 + 상품ID`로 조인한다.
- 습식, 반건조, 미상 형태는 수분이 없으면 건물기준 값도 결측이다.

## 4. 사용 시 주의사항

1. **heart는 85건으로 카테고리 채택 기준(97건)보다 적다.**
   - 기준은 모비율 95% 신뢰구간, 허용 오차 ±10%p, 5-fold 교차검증이다.
   - 채택을 판정할 때는 용량 변형이 중복으로 포함돼 있어 기준을 넘었다. 보류로 돌릴지는 아직 정하지 않았다.
2. **출처 편중:** 모든 카테고리에서 다나와 비중이 가장 크다. 특히 vision은 거의 다나와다. 모델이 기능 대신 출처의 특징을 배울 수 있으므로, 평가할 때 출처별 성능도 확인한다. `출처`를 입력 피처로 넣을지도 이 위험을 고려해 정한다.
3. **용량 변형 사이의 라벨 불일치:** 용량만 다른 같은 상품 중 36개 그룹은 용량별로 학습카테고리가 달랐다. 이 파일은 각 그룹의 첫 행만 남겼다.
4. **성분만으로 구분되는 카테고리는 일부뿐이다.**
   - 같은 출처 안에서 비교해도 차이가 유지되는 카테고리는 renal_urinary(단백질·섬유·회분은 낮고 지방은 높음)와 weight_management(지방은 낮고 섬유는 높음)다.
   - digestive, skin_coat, heart는 네 성분 모두 차이가 거의 없다 (`project/EDA/gold_unified_eda.ipynb` 5절).
   - 이 분석은 용량 변형, 이상치, 사료형태 복수값을 빼기 전의 데이터로 했다.
5. **`상품ID`, `상품명`, `출처`는 식별용이다.** 모델 입력에서 뺀다. 출처를 피처로 쓰려면 2항을 먼저 검토한다.
